# spare-veri

Spare uygulamasının okuduğu herkese açık etkinlik listesi. Bu depoyu bot günceller, elle değiştirme.

- `events.json`: yayındaki etkinlikler (bizim yazdığımız açıklamalarla)
- `changes.json`: son 7 günün iptal ve değişiklikleri
- `review.json`: onay bekleyen metinler (onay sayfası okur)
